## 15. ANNEXES

### 15.1 Glossaire

**Termes Métier** :

- **GMV (Gross Merchandise Value)** : Valeur totale des transactions sur la plateforme (prix payés par clients avant déduction commissions)

- **Take Rate** : Pourcentage de commission prélevé par la plateforme sur chaque transaction

- **Unit Economics** : Rentabilité par unité (client ou transaction), calculée comme : Revenus par unité - Coûts par unité

- **CAC (Customer Acquisition Cost)** : Coût moyen pour acquérir un nouveau client

- **LTV (Lifetime Value)** : Valeur totale qu'un client apportera sur toute sa durée de vie

- **Churn Rate** : Taux d'attrition, pourcentage d'utilisateurs qui cessent d'utiliser le service

- **Liquidity** : Équilibre entre l'offre (prestataires) et la demande (clients) sur la plateforme

- **Marketplace** : Modèle économique où la plateforme connecte l'offre et la demande sans posséder les actifs

- **Supply Side** : Côté offre de la marketplace (les prestataires)

- **Demand Side** : Côté demande de la marketplace (les clients)

**Termes Techniques** :

- **API (Application Programming Interface)** : Interface permettant à différentes applications de communiquer

- **JWT (JSON Web Token)** : Standard d'authentification sécurisé pour les APIs

- **WebSocket** : Protocole de communication bidirectionnelle en temps réel

- **OCR (Optical Character Recognition)** : Technologie de reconnaissance de caractères dans les images

- **KYC (Know Your Customer)** : Processus de vérification d'identité des utilisateurs

- **IPN (Instant Payment Notification)** : Notification instantanée de paiement (webhook)

- **CDN (Content Delivery Network)** : Réseau de serveurs distribuant du contenu optimisé

### 15.3 Cadre Légal Tunisien

#### 15.3.1 Statut Juridique Recommandé

**SARL (Société à Responsabilité Limitée)** :
- Capital minimum : 1 TND (symbolique)
- Nombre d'associés : 1 à 50
- Responsabilité limitée aux apports
- Régime fiscal : IS (Impôt sur les Sociétés)

**Procédure de création** :
1. Rédaction statuts (avocat : 500-1000 TND)
2. Dépôt capital banque
3. Enregistrement actes (300 TND)
4. Publication JORT (200 TND)
5. Immatriculation RNE (100 TND)
6. Patente municipale (150 TND)

**Durée totale** : 2-4 semaines
**Coût total** : ~2000 TND

#### 15.3.2 Obligations Fiscales

**TVA (Taxe sur la Valeur Ajoutée)** :
- Taux : 19% sur services
- Assujettissement obligatoire si CA > 100K TND/an
- Déclaration : Mensuelle ou trimestrielle
- Facturation électronique obligatoire (2024+)

**IS (Impôt sur les Sociétés)** :
- Taux standard : 25%
- Taux réduit : 10% (selon activité)
- Acomptes provisionnels trimestriels
- Déclaration annuelle avant 25 mars N+1

**Retenue à la source** :
- 1.5% sur honoraires prestataires personnes physiques
- Déclaration employeur mensuelle

**Cotisations sociales** (pour employés) :
- CNSS : 16.57% (employeur) + 9.18% (salarié)
- Déclaration trimestrielle

#### 15.3.3 Protection des Données (INPDP)

**Loi n°2004-63 sur la protection des données personnelles** :

Obligations :
- Déclaration auprès de l'INPDP avant collecte
- Consentement explicite utilisateurs
- Sécurisation des données
- Droit d'accès et rectification
- Droit à l'oubli
- Notification violations dans les 72h

**Procédure déclaration INPDP** :
1. Formulaire en ligne (www.inpdp.tn)
2. Description traitements données
3. Mesures sécurité mises en place
4. Durée conservation
5. Délai réponse : 1-2 mois
6. Coût : Gratuit

#### 15.3.4 Statut Prestataires

**Options pour prestataires** :

1. **Auto-entrepreneur (Personne Physique)** :
   - Régime simplifié
   - Pas de comptabilité lourde
   - Plafond CA : 75K TND/an
   - Impôt libératoire : 2% du CA
   - Pas de TVA

2. **Micro-entreprise** :
   - CA entre 75K et 300K TND/an
   - Régime réel simplifié
   - TVA applicable
   - Comptabilité simplifiée

3. **Société (SARL unipersonnelle)** :
   - Pas de plafond CA
   - Responsabilité limitée
   - Crédibilité accrue
   - Charges plus élevées

**Recommandation plateforme** :
- Encourager auto-entrepreneuriat pour débuter
